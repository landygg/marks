# Keyboard shortcuts

[Español](../es/shortcuts.md) · **English**

## In the app

| Shortcut | Action |
|---|---|
| ⌘K | Open the command palette |
| ⌘N | Add bookmark |
| ⌘, | Open Settings |
| ⌃⌘S | Show or hide the sidebar |
| ⌥⌘1 … ⌥⌘9 | Switch to profile 1 … 9, by its position in the rail |

## Inside the palette

| Shortcut | Action |
|---|---|
| ⌘1 | “Commands” mode |
| ⌘2 | “Bookmarks” mode (search) |
| ⌘3 | “Tags” mode |
| ↑ / ↓ | Move the selection |
| ↵ | Run the command or open the result |
| esc | Close the palette |

## In the browser

| Shortcut | Action |
|---|---|
| ⌥⇧M | Save the current tab to marks (extension) |

This is the shortcut the extension suggests. Change it in the browser's extension shortcut settings.

## App menu

The marks menu on macOS carries the usual system shortcuts: ⌘Q to quit, ⌘W to close the window (marks stays in the menu bar), ⌘H to hide, and cut, copy, paste, undo and select all in text fields.

## Notes

- The app's shortcuts can't be changed.
- ⌃⌘S does nothing while a dialog is open.
- The detail's actions have no shortcuts of their own: run them by name from the palette (⌘K). See [Search and the command palette](search.md).
- Resize the areas by dragging the gap between them. With the focus on that gap, the arrow keys work too.
