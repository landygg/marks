# Atajos de teclado

**Español** · [English](../en/shortcuts.md)

## En la app

| Atajo | Acción |
|---|---|
| ⌘K | Abrir la paleta de comandos |
| ⌘N | Añadir bookmark |
| ⌘, | Abrir Ajustes |
| ⌃⌘S | Mostrar u ocultar la barra lateral |
| ⌥⌘1 … ⌥⌘9 | Cambiar al perfil 1 … 9, según su posición en el carril |

## Dentro de la paleta

| Atajo | Acción |
|---|---|
| ⌘1 | Modo «Comandos» |
| ⌘2 | Modo «Bookmarks» (buscar) |
| ⌘3 | Modo «Etiquetas» |
| ↑ / ↓ | Mover la selección |
| ↵ | Ejecutar el comando o abrir el resultado |
| esc | Cerrar la paleta |

## En el navegador

| Atajo | Acción |
|---|---|
| ⌥⇧M | Guardar la pestaña actual en marks (extensión) |

Este atajo es el que propone la extensión. Se cambia en los ajustes de atajos de extensiones del navegador.

## Menú de la app

El menú de marks en macOS trae los atajos habituales del sistema: ⌘Q para salir, ⌘W para cerrar la ventana (marks sigue en la barra de menús), ⌘H para ocultar, y cortar, copiar, pegar, deshacer y seleccionar todo en los campos de texto.

## Notas

- Los atajos de la app no se pueden cambiar.
- ⌃⌘S no actúa mientras hay un diálogo abierto.
- No hay atajo propio para cada acción del detalle: todas se ejecutan por su nombre desde la paleta (⌘K). Ver [Buscar y paleta de comandos](search.md).
- Las zonas se redimensionan arrastrando el hueco entre ellas. Con el foco en ese hueco, también con las flechas del teclado.
