# Security

[Español](#español) · **English**

## Reporting a vulnerability

Don't open a public issue. Report it privately through [GitHub's security advisories](https://github.com/landygg/marks/security/advisories/new): only the maintainers see it.

Include what you found, how to reproduce it, and which version of marks (and of the browser extension, if it's involved) you used. Don't include your real bookmarks, the extension token or an API key.

## Supported versions

Only the latest release gets security fixes.

## Español

No abras un issue público. Infórmalo en privado con los [avisos de seguridad de GitHub](https://github.com/landygg/marks/security/advisories/new): solo lo ven los mantenedores.

Incluye lo que encontraste, cómo reproducirlo y qué versión de marks usabas (y de la extensión, si interviene). No incluyas tus bookmarks reales, el token de la extensión ni una clave de API.

Solo la última versión recibe arreglos de seguridad.
